# Arka plan figürleri — kaynaklar ve lisanslar

Tekrar ve Egzersiz'de soru ekranının boş alanındaki silik figürler
(`ios/App/Assets.xcassets/Figures`, 2026-09-14). Hepsi **kamu malı**
(Wikimedia Commons'ta lisans satırı "Public domain"; alt etiketleri
PD-old-100-expired / PD-old-70-expired / PD Old). CC-BY ve CC-BY-SA
dosyalar bilerek elendi.

İşleme: `evals/tools/engrave.py` — kırpma, (yüksükotunda) alt figür
maskeleme, kâğıt normalizasyonu, mürekkep → saydamlık, 900 px, 32 alfa kademesi.
Ham indirmeler repoya konmadı; aşağıdaki bağlantılardan yeniden alınabilir.
